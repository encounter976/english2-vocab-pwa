# 英语（二）AI 单词本 V4.1｜拍照识词版

这版基于 V4 DeepSeek 浏览器直连 PWA 更新，核心变化只有一件：

**扫描功能不再识别文章和句子，只识别英文单词。**

适用场景：
- 手写一个英文单词，拍照识别
- 一张纸上写多个单词，拍照识别
- 单词表、笔记上的印刷体单词
- 英语试卷/真题上的英文单词
- 手写体和印刷体混合图片

## 使用流程

1. 打开“加词” → “拍照识别单词”
2. 拍照或从相册选择图片
3. 点“识别单词”
4. DeepSeek Vision 只返回图片里识别到的英文单词
5. 点需要记忆的单词
6. 单词进入词库，并由 DeepSeek 文本模型自动生成词卡

识别阶段不会：
- 翻译文章
- 输出全文
- 分句
- 分析题目
- 自动把所有词加入词库

## 识别规则

- 支持手写体与印刷体
- 保留图片里的实际词形，例如 `studied`、`circumstances`
- 自动去除标点、数字和中文
- 大小写不敏感去重
- 最多返回 150 个唯一英文单词
- 看不清的词要求模型不要猜

## AI 词卡

点选某个识别出来的词后，仍会自动生成：
- 原形/词元
- 音标
- 词性
- 常用中文义
- 英语（二）优先义
- 常见搭配
- 例句与翻译
- 同根词
- 记忆提示

## DeepSeek API

本版保持 V4 的“浏览器直连”架构：
- 不需要 Cloudflare Worker
- 不需要 APP_TOKEN
- DeepSeek API Key 由用户在设置页输入
- Key 保存在当前浏览器本地，不写入网页源码

默认 API Base：
`https://api.deepseek.com`

## PWA 文件

部署时请把以下文件放在同一静态网站目录：
- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `icon-192.png`
- `icon-512.png`
- `apple-touch-icon.png`

Safari 打开网站后可“添加到主屏幕”。

## 升级说明

本版继续沿用上一版的浏览器数据键，因此在**同一个域名**上覆盖部署 V4.1 时：
- 已有单词保留
- 笔记保留
- 复习记录保留
- DeepSeek API Key 设置保留

Service Worker 缓存版本已更新，部署后重新打开网页即可拉取新版。
